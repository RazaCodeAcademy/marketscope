# MarketScope website

Static landing page for a product-research browser extension in development.

## Before publishing
- Replace `[REPLACE WITH YOUR REAL CONTACT EMAIL]` in `index.html` and `privacy.html`.
- Replace `[REPLACE WITH PUBLICATION DATE]` in `privacy.html`.
- Review all claims for accuracy; update the privacy policy to reflect actual data practices and permissions before launch.
- If your extension is already live, update the 'in development' and 'not accepting registrations' wording.

## Publish with GitHub Pages
1. Create a public GitHub repository named `marketscope`.
2. Upload `index.html`, `privacy.html`, and this `README.md` to the repository root.
3. Open Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/ (root)` and click Save.
5. Visit `https://YOUR_USERNAME.github.io/marketscope/` after deployment.
